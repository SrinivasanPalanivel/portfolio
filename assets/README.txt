ICON FILES FOR THE SKILLS SECTION
=================================
Put one logo per tool in this folder. Use the exact file names below
(lowercase). Accepted formats: .svg (best), .png, .webp, .jpg.

If a file is missing, that tool simply shows as a plain text label, so
nothing breaks. Replace any file here with the official logo and
refresh the page.

selenium        playwright      restassured     appium
testng          cucumber        postman         jmeter
java            javascript      typescript      postgresql
jenkins         githubactions   git             github
maven           jira            qmetry          testrail
agileaccelerator
aws             linux
githubcopilot   m365copilot     claudecode

Starter icons are already included for: cucumber, postman, java,
javascript, typescript, postgresql, jenkins, githubactions, git,
github, maven, jira, aws, linux. Overwrite them with your own if you
prefer. Selenium and Playwright are intentionally not included.

Tip: logos show on a small white square, so transparent PNG/SVG
files work best. Square images look cleanest.
